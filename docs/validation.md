## 보존한 규칙과 달라지는 결과

### 검수

- 첫 열의 제품명에 대응하는 코드프레임을 선택하고, 문항 불일치 양방향·동일 문항 중복 코드·Sub-Net 코드 존재·Net 누락을 확인한다.
- 첫 시트를 사용한다. 응답 시트가 1개가 아니거나 코드프레임 시트가 2개보다 많으면 알리면서 첫 시트 검수를 계속한다.
- 원래 중복 헤더를 직접 읽으므로 pandas가 덧붙이는 `.1`~`.59`를 지우는 처리가 필요하지 않다. 실제 문항명에 포함된 `.1`도 보존한다.
- Sub-Net 세부 항목은 기존처럼 이름에 소문자 `subnet`이 포함되는 열이다. 대소문자를 자동 변환하지 않는다.
- 비어 있지 않은 코드는 비음수 정수만 허용한다. 숫자 `1`, `1.0`과 문자열 `"1.0"`, `"001"`은 동일한 정수 코드로 비교한다. 소수·음수·불리언·지수 표기 문자열은 강제로 변환하지 않고 보고한다.
- 응답 코드의 빈 셀은 비교에서 제외한다. 코드프레임의 빈 코드는 검수 항목으로 보고한다. 잘못된 값이 있어도 나머지 검수를 계속한다.
- `없다`, `없음`, `모름/무응답`, `모름`, `무응답`의 Net은 수동 확인 목록이다. `기타`로 자동 변경하거나 다른 Net을 곧바로 오류로 단정하지 않는다.
- 검수 결과의 행·열은 Excel의 1부터 시작하는 위치다. `CODEFRAME_*`, `DUPLICATE_CODE`, `MISSING_NET`은 코드프레임 위치이고 `INVALID_SUBNET`, `UNKNOWN_CODE`는 응답 파일 위치다.
- 명령 종료 코드는 문제 없음 0, 검수 항목 발견 1, 파일 등 실행 실패 2다. 검수는 원본 파일을 수정하지 않는다.

### 전처리

- 문자 정리 → 띄어쓰기 → 맞춤법 → 명사 추출 순서와 `text`, `corrected_text`, `spell_check_text`, `tokenized_text` 열을 유지한다.
- 정제 함수가 원래 입력을 그대로 반환하던 오류를 수정했다. HTML·이메일·URL은 구두점 제거 전에 처리하며 URL 경로도 제거한다. 앞뒤 공백을 정리한다. 이 수정은 기존 출력 텍스트와 후속 군집 결과를 바꾼다.
- 결측·비문자열 응답은 외부 처리 전에 거부한다. 응답을 자동 삭제하거나 `"nan"` 등으로 변환하지 않는다. 처리기 실패를 정상 결과로 대체하지 않는다.
- SQL은 선택한 테이블의 `response` 열만 조회하며 쓰기 SQL이나 commit은 호출하지 않는다. DB의 과거 조회 순서는 보장된 정렬 규칙이 없으므로 새 정렬을 추가하지 않았다.
- 연결은 성공·실패 모두 닫는다. 설정 값이나 응답이 포함될 수 있는 외부 예외 원문은 명령에서 출력하지 않는다.
- 저장 전에 Excel 직렬화를 완료한다. 출력이 존재하면 기본적으로 중단하며, 덮어쓰기 옵션이 있을 때만 기존 파일을 연다. 디스크·운영체제 쓰기 실패까지 원자적으로 복구하는 기능은 제공하지 않는다.

### 군집 탐색

- TF-IDF의 `min_df=0.0`, `max_df=1.0`, `max_features=50`, `ngram_range=(1, 2)`와 DBSCAN의 `eps=(0.1, 0.5, 1.0)`, `min_samples=(2, 3, 5)`를 유지한다.
- DBSCAN에는 유사도 대신 코사인 거리를 넣는다. `metric='precomputed'`는 거리 행렬을 받는다는 [공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.DBSCAN.html)에 따른 수정이며, 과거 군집 라벨을 재현하는 변경이 아니다.
- 군집 수는 실제로 존재하는 잡음 라벨 `-1`만 제외한다. 군집 수가 가장 많은 조합을 고르며 동률이면 처음 조합을 유지한다. 모든 조합에서 군집이 없어도 첫 조합과 잡음 라벨을 반환한다. 이 기준을 의미적 군집 품질의 최적화나 모델 성능 검증으로 해석하지 않는다.
- t-SNE는 기존처럼 코사인 유사도 행벡터를 특징으로 사용한다. 난수 시드는 42이며 perplexity 기본값은 30이다. [공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.TSNE.html)의 표본 수 조건을 확인한다.
- 명령은 조합별 군집 수·잡음 수를 출력하며 응답 원문과 TF-IDF 전체 행렬은 출력하지 않는다. `--no-plot`은 t-SNE 계산·그래프 표시를 생략한다. 군집 데이터는 함수 반환값으로 제공하고 별도 파일을 자동 저장하지 않는다.
- 문서 간 밀집 거리 행렬을 계산하므로 메모리는 문서 수의 제곱에 비례한다. 명령의 예상 크기는 행렬 하나의 크기이며 전체 메모리 상한이 아니다. 대규모 데이터 실행은 검증하지 않았다.

## 미검증 범위와 실행 전 확인

- 원본 업무 Excel·코드프레임 및 MySQL 접속 환경이 없어 실제 형식·전체 업무 재현은 미검증이다. 현재 검수 규칙을 업무에 다시 적용하기 전 양식 대조가 필요하다.
- PyKoSpacing·hanspell·KoNLPy는 설치·실행하지 않았다. 전처리 명세는 pandas·Excel 엔진·MySQL Connector만 제공한다. 실제 전처리에는 호환되는 Python·모형 환경과 각 패키지를 별도로 준비해야 한다.
- [PyKoSpacing](https://github.com/haven-jeon/PyKoSpacing)의 모형 의존성과 [KoNLPy 설치 안내](https://konlpy.org/en/latest/install/)의 Java·JPype 조건을 확인해야 한다. 현재 코드가 새로운 모형이나 백엔드를 자동 선택하도록 바꾸지는 않았다.
- [hanspell 공개 구현](https://github.com/ssut/py-hanspell/blob/master/hanspell/spell_checker.py)은 문장을 외부 요청으로 보내며 길이 제한·서비스 응답에 영향을 받는다. 실제 서비스의 현재 동작이나 업무 데이터 전송 허용 여부는 검증하지 않았다. 실패 시 문장 분할이나 다른 서비스로의 대체는 자동으로 수행하지 않는다.
- 실제 업무 데이터의 군집 적합성, 공급기업 모델의 정확도, 대시보드·플랫폼 운영 결과는 검증 대상에 포함되지 않는다.

현재 승인된 범위는 합성·대체 자료로 검증하는 코드 정제다. 실제 환경 검증은 위 조건이 확보되었을 때 별도 범위를 정해 진행한다.
